## Hyperlinks

Hyperlinks are used in report navigation. Also it is possible to use the **Interaction.Bookmark** and **Interaction.Tag** properties for this. A hyperlink is set using the **Interaction.Hyperlink** property. During report rendering, the expression, specified in this property, is set to the **Interaction.HyperlinkValue** property. This setting occurs during report rendering. There are three ways of specifying hyperlinks. It is possible to use one of them.
