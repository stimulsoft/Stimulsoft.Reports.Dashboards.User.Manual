## Report Bands

There are two report bands in Stimulsoft Reports: the **Report Title** and the **Reports Summary** **bands**. The Report Title band is output at the beginning of a report and the Report Summary band is output at the end of a report. The number of **Report Title** and **Report Summary** bands on a page is unlimited. The **Report Title** and the **Report Summary** bands can be output more than one time and can be used on each page.
