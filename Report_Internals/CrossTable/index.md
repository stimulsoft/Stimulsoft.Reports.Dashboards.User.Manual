## Cross-Tab

The **Cross table** is a special component that is used to process, group and summarize data from the data source. The result is represented as a table. The **Cross table** can be placed both directly on a page or on a **Data** band. If a table that is created as a result of a **cross table** rendering does not fit on one page, then it can be printed on several pages. The component has many properties and settings.
