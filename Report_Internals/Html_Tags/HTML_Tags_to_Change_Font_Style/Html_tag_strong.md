## HTML &lt;strong&gt; Tag

The &lt;**strong**&gt; tag indicates strong emphasis. It has an end tag. Text within this tag is more important than flat text. It is usually rendered in bold font style. The example below shows how the &lt;**strong**&gt; tag works:

Text &lt;strong&gt;Text&lt;/strong&gt; Text

The result of output:

Text **Text** Text
