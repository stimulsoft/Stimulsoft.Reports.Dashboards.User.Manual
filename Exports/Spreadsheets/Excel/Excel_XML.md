## Excel XML

For storing documents as the basic Microsoft Excel format, right up to the Excel 2007 version, Excel used its own binary format of files (BIFF) and the file extension was «.xls». In **Excel 2003** additionally, a new format based on XML (XMLSS) was used. This open format is convenient for developers and is data oriented. The basic disadvantage of the format is the impossibility to embed raster images.
