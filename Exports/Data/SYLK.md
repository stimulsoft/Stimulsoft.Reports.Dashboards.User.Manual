## SYLK

**SYLK** (Symbolic Link) format - this text format is used to exchange data between applications, specifically spreadsheets. SYLK files have the «**.slk**» extension. Microsoft does not publish a SYLK specification, therefore, working with this format in different applications may differ.


* **Note:** A SYLK file can be written in Unicode and read by some applications but anyway many applications which do support Unicode write SYLK files into ANSI but not Unicode. Therefore, symbols which do not have representation in the system code page will be written as ('?') symbols.
