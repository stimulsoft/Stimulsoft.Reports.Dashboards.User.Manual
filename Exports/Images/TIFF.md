## TIFF

**TIFF** (Tagged Image File Format) is a file format for storing images. Originally, the TIFF format was created by the Aldus company in cooperation with Microsoft for use with PostScript. TIFF became popular for storing high-color-depth images, and is used for scanning, faxing, text recognition, and polygraphy (printing), and is widely used in graphic applications. This format is flexible. It allows saving photos in different color spaces, using different algorithms of file compression, and storing a few images in one file.
